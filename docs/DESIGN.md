# V1 설계 요약

## 예측 대상

1. 향후 6개월 자본유입 지속·가속 점수
2. 향후 12개월 산업 붐 전환 점수
3. 향후 24개월 핵심산업 이동 점수
4. 시장 미반영 점수
5. 최종 선투자 기회점수

모든 값은 초기에는 0~100 점수이며 확률이 아니다.

## 핵심 발견 논리

- 높은 절대 투자액보다 증가 속도와 가속도를 중시
- 한 기업의 대형 투자보다 산업 내 확산도를 중시
- 발표보다 실제 집행, 장비발주, 수주잔고를 중시
- 실물지표가 강하고 시장관심이 낮은 괴리를 보상
- 주가·ETF·검색량만 강한 경우 과열로 감점
- 공급과잉과 정책의존 위험을 별도 감점

## 데이터 계층

- 기업: CAPEX, R&D, 시설투자, 직원, 수주, 재고
- 산업: 생산, 출하, 재고, 가동률, 수출입, 신규주문
- 정책: 예산, 보조금, 조달, 프로젝트 승인
- 혁신: 특허, 논문, 상용화, 기술단가
- 시장: 상대강도, ETF, 거래대금, 밸류에이션, 관심도
- 거시: 기존 글로벌 거시엔진 결과를 그대로 입력

## 검증 로드맵

성공사례와 실패사례를 함께 사용하여 과거 시점의 데이터만으로 워크포워드 검증한다. 생성형 AI, 클라우드, 스마트폰, 전기차·배터리뿐 아니라 메타버스, 과잉투자 구간, 정책 발표 후 집행이 약했던 산업을 포함한다.
